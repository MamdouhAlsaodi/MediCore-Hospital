# Security Policy

MediCore Hospital is an educational, synthetic-data project. It is not clinical software, a deployed service, or a supported production system. The local security controls and tests are demonstrations, not a security certification or a response-time promise.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/MamdouhAlsaodi/MediCore-Hospital/security/advisories/new) for this repository. Private reporting is enabled. Please do not open a public issue with an exploit, credential, token, patient record, or other sensitive material. Do not test against systems or data you do not own.

For ordinary non-sensitive bugs and documentation issues, use [GitHub Issues](https://github.com/MamdouhAlsaodi/MediCore-Hospital/issues).

## Scope

Only the source in this repository and its synthetic local review setup are in scope. There is no hosted clinical instance, real-data environment, or production security support. Maintainers will review reports on a best-effort basis; no disclosure or remediation SLA is promised. Never submit real patient or personal data as a reproduction fixture.
